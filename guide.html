🚀 LTLMS Docker Deployment Guide (Ubuntu)

Prerequisites:
  • Ubuntu 20.04 or later
  • User with sudo privileges
  • Internet connection
  • Git installed (sudo apt install git)

1️⃣ Install Docker & Docker Compose

Update your system and install Docker Engine and Compose:

sudo apt-get update
sudo apt-get install -y ca-certificates curl git
sudo install -m 0755 -d /etc/apt/keyrings
sudo curl -fsSL https://download.docker.com/linux/ubuntu/gpg -o /etc/apt/keyrings/docker.asc
sudo chmod a+r /etc/apt/keyrings/docker.asc

echo "deb [arch=$(dpkg --print-architecture) signed-by=/etc/apt/keyrings/docker.asc] \
https://download.docker.com/linux/ubuntu $(. /etc/os-release && echo "${UBUNTU_CODENAME:-$VERSION_CODENAME}") stable" | \
sudo tee /etc/apt/sources.list.d/docker.list > /dev/null

sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io docker-buildx-plugin docker-compose-plugin

Optional: If you need legacy Compose v1:

sudo apt-get install -y docker-compose

2️⃣ Clone the LTLMS Project

git clone https://github.com/pythonair98/LTLMS.git
cd LTLMS

3️⃣ Build and Run the Project

Build and launch the project using Docker Compose:

docker compose -f docker-compose.simple-logging.yml up --build

To run in the background (detached mode):

docker compose -f docker-compose.simple-logging.yml up --build -d

4️⃣ What Happens on First Run?

  • All required Python dependencies are installed in the container.
  • MySQL database is initialized and migrations are applied for all apps.
  • Initial data is loaded automatically via init_data.py:
    • Superuser manager (password: manger@2025#) is created.
    • Default Occupations and Teams are created/updated.
    • Superuser profile is created and assigned to the first team and "Licensing Department Director" occupation.
    • All Activities are created/updated.
  • Django development server is started on http://localhost:8000.

5️⃣ Access the Application

  • Open http://localhost:8000 in your browser.
  • Login to the admin panel at /admin/ with:
    Username: manager
    Password: manger@2025#

6️⃣ Useful Docker Commands

# Check running containers
docker ps

# Stop the project
docker compose -f docker-compose.simple-logging.yml down

# View logs
docker compose -f docker-compose.simple-logging.yml logs -f

# Run a command inside the web container
docker compose -f docker-compose.simple-logging.yml exec web bash

7️⃣ Troubleshooting

  • Port already in use: Change the port in docker-compose.simple-logging.yml or stop the service using that port.
  • Database errors: Ensure MySQL is running and healthy. The container will retry until ready.
  • ModuleNotFoundError: Make sure all app folders are present and not excluded by .dockerignore.
  • Permission denied: Ensure the logs/ directory exists and is writable, or remove the volume mount if not needed.
  • Migrations not applied: The container runs all migrations on startup. You can also run them manually:
    docker compose -f docker-compose.simple-logging.yml exec web python manage.py migrate --settings=LTLMS.settings_docker_simple
  • Superuser/initial data missing: The init_data.py script runs on every container start and is idempotent.

8️⃣ (Optional) Allow Docker Without Sudo

sudo usermod -aG docker $USER
newgrp docker

9️⃣ (Optional) Clean Up

# Remove all stopped containers, unused networks, images, and build cache
docker system prune -a --volumes

✅ You're Ready!

Your LTLMS project is now running in Docker. Enjoy!
